## 2. 重构计划

### 2.1 目标结构

```
main/app/
├── lan_mic_app.h/.cc           # 主控制器（协调器，不再含绘制逻辑）
├── pages/
│   ├── chat_page.cc/.h         # 对话页面（气泡、滚动、状态提示）
│   ├── settings_page.cc/.h     # 设置页（菜单、交互、电池预览）
│   ├── weather_page.cc/.h      # 天气看板（图标匹配、预报卡片）
│   ├── almanac_page.cc/.h      # 黄历页面
│   ├── lifebar_page.cc/.h      # 人生进度条
│   ├── countdown_page.cc/.h    # 倒计时（时间计算、报警）
│   └── page_base.h             # 页面基类接口
├── protocol/
│   ├── wss_client.cc/.h        # WSS 通信 + 认证 + 消息路由
│   └── todo_sync.cc/.h         # Todo 离线同步
└── widgets/
    ├── battery_widget.cc/.h    # 电池图标组件（横/纵切换）
    └── wifi_icon.cc/.h         # WiFi 状态图标
```

### 2.2 重构原则

1. **增量拆分**：每次只拆一个页面，确保编译通过再拆下一个
2. **接口稳定**：先定义页面基类接口 `PageBase`，再逐个迁移
3. **状态外移**：页面状态从 `lan_mic_app.h` 迁移到各自 `.h`
4. **主类瘦身**：`LanMicApp` 只保留：事件循环、WS 通信、音频流、页面调度
5. **注释补充**：拆分时同步补充分页注释和函数文档

### 2.3 拆分优先级

| 优先级 | 页面 | 原因 | 预估行数 |
|--------|------|------|----------|
| P0 | `chat_page` | 最复杂（~200行内联），使用频率最高 | ~300 行 |
| P1 | `settings_page` | 交互逻辑复杂（菜单/预览/切换） | ~200 行 |
| P1 | `countdown_page` | 独立状态机，天然适合拆分 | ~150 行 |
| P2 | `weather_page` | 已抽出函数，拆分简单 | ~100 行 |
| P2 | `almanac_page` | 已抽出函数，拆分简单 | ~60 行 |
| P2 | `lifebar_page` | 已抽出函数，拆分简单 | ~70 行 |
| P3 | `protocol/` | WSS + Todo 同步 | ~400 行 |
| P3 | `widgets/` | 电池 + WiFi 图标 | ~100 行 |
