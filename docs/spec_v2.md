# 墨水屏智能助手固件优化 Spec (v2)

## 1. 概述
- **目标设备**: ZecTrix Note 4, ESP32-S3, 4.2寸墨水屏 (400x300分辨率, 单色)
- **ESP-IDF**: v6.0, C++17
- **开发原则**: 所有改动在应用层 (`lan_mic_app.cc` 等)，**不修改底层 WiFi/音频驱动**。

## 2. 状态栏 (Status Bar)
- **位置**: 屏幕顶部固定区域
- **WiFi 状态图标**: 
  - 未连接/断开: 带叉号或灰色 Wi-Fi 图标
  - 连接中: 闪烁的 Wi-Fi 图标
  - 已连接: 实心 Wi-Fi 图标
- **后端服务状态**:
  - WSS 握手未成功: "服务离线" 或 云端图标置灰
  - WSS 长链接建立: "在线" 或 云端图标高亮
  - 异常提示: WiFi 正常但后端无法连接时，提示 "服务器连接失败"
- **电池显示优化**:
  - 竖向电池轮廓 + 动态填充柱状条 + 旁边显示具体百分比数值 (如 `85%`)
  - 低于 20% 时，柱状条反白/闪烁提示

## 3. 对话页面 (Chat UI)
- **布局**: 类聊天软件的气泡布局
- **用户发言 (右侧)**: 识别出的文字或 "语音输入中..."，右侧对齐，实心气泡/深色边框
- **系统回复 (左侧)**: 大模型流式返回文本，左侧对齐，边框气泡/浅色填充
- **交互细节**:
  - 等待回复时左侧显示 "正在思考..."
  - 录音时右侧显示 "正在录音..." 或状态提示
  - 对话历史支持上下滚动，最新消息自动滚到可视区域

## 4. 设置页面 (Settings)
- **扁平化设计**: 解决当前 "设置套设置" 的冗余层级，改为单列列表菜单
- **菜单项 (全汉化)**:
  - **网络管理**: 
    - Wi-Fi 控制 (显示当前 SSID, 断开/重连)
    - 服务控制 (显示状态, 断开/重连)
  - **系统控制**:
    - 音量调节 (加减选项或显示当前等级，如 "音量：中")
    - 电源管理 (重启设备/关机，需二次确认或直执)
- **交互**: 单列列表，选中项高亮显示，去除底部冗余导航栏

## 5. 智能倒计时 (Countdown Timer)
- **交互流程**:
  1. 用户语音指令: "帮我定一个5分钟的泡面倒计时"
  2. ASR -> LLM 识别意图
  3. LLM 返回结构化 JSON 数据: `{"type": "timer", "duration": 300, "label": "泡面"}`
  4. 固件解析 JSON，若 `type == "timer"`，跳转进入 "倒计时模式"
- **倒计时 UI**:
  - 屏幕中央大号字体剩余时间 (如 `04:59`)
  - 下方显示事项标签 (如 `泡面`)
- **提醒机制**:
  - 倒计时归零触发音频提醒
  - 循环策略: 播放提示音 (叮/哔)，**循环 5 次**
  - 停止条件: 用户按任意键停止提醒并关闭倒计时页面
- **⚠️ 防呆处理 (JSON 解析)**:
  - LLM 偶尔会返回 ````json ... ```` 格式的 Markdown 标签。
  - 解析前必须先**剥离**开头的 ````json` 和结尾的 ```，再进行 JSON 解析。
  - 提取逻辑: 搜索 `{"` 开始位置到最后一个 `}` 结束位置，截取有效内容再解析。

## 6. UI 视觉规范 (400x300 墨水屏)
- **字体**: 清晰的无衬线字体，确保小字号清晰可辨
- **配色**: 黑白两色为主，利用边框、填充、灰度抗锯齿区分元素
- **空间利用**: 信息密度与可读性平衡，注重排版留白
- **反馈**: 所有操作（选中、开始/结束、按键）需有明确的视觉反馈（反色）或听觉反馈

## 7. 开发约束
- **编译验证**: 写完后请执行 `source ~/Documents/esp/v6.0/esp-idf/export.sh && idf.py build` 确保代码无编译错误。
- **不打包发布**: 编译通过后即可，**不需要**执行 `idf.py merge-bin` 或打包 zip 文件。由我负责最终打包。
- **底层保护**: 严格保护 WiFi 驱动、音频录制/播放驱动，仅改应用层。
- **数据持久化**: Wi-Fi配置、音量设置等利用现有存储机制 (NVS/Settings)。
- **WSS 通信**: 保持现有长链接，新增倒计时 JSON 数据需在现有协议中透传。
