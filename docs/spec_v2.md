# 墨水屏智能助手固件优化 Spec (v3)

## 1. 概述
- **目标设备**: ZecTrix Note 4, ESP32-S3, 4.2寸墨水屏 (400x300分辨率, 单色)
- **ESP-IDF**: v6.0, C++17
- **开发原则**: 所有改动在应用层 (`lan_mic_app.cc` 等)，**不修改底层 WiFi/音频驱动**。
- **编译验证**: 写完后请执行 `source ~/Documents/esp/v6.0/esp-idf/export.sh && idf.py build` 确保代码无编译错误。
- **不打包发布**: 编译通过后即可，**不需要**执行 `idf.py merge-bin` 或打包 zip 文件。

## 2. 状态栏 (Status Bar)
- **位置**: 屏幕顶部固定区域 (Y: 0-24 或类似)
- **页面标题**: 每个页面**必须**有明确的标题（如"对话"、"设置"、"天气"、"黄历"、"人生进度"），显示在状态栏中间。
- **WiFi 状态图标**: 实心/闪烁/叉号。
- **后端服务状态**: 在线/离线。
- **电池显示优化 (重要)**:
  - **样式**: **横向 3 节电池**。
  - **逻辑**: 外包矩形框，内部按 3 格划分。
    - 0-33%: 显示 1 格 (最左)
    - 34-66%: 显示 2 格
    - 67-100%: 显示 3 格 (全满)
  - **低电量**: 红色/反白警告 (如低于 20%)。

## 3. 对话页面 (Chat UI)
- **布局**: 类聊天软件的气泡布局。
- **用户发言 (右侧)**:
  - **气泡**: 圆角矩形，**实心填充 (黑底白字)**。
  - **对齐**: **完全右对齐**，紧贴右边缘 (X = 400 - 宽度 - 边距)。
  - **内容**: 气泡**内部**包裹文字，**绝不要**画出空框或框外文字。
- **系统回复 (左侧)**:
  - **气泡**: 圆角矩形，**细线边框 (白底黑框)**。
  - **对齐**: 紧贴左边缘。
- **录音/识别逻辑**:
  - 录音时：右侧显示 "正在录音..." (干净界面，**不要**出现旧消息气泡)。
  - 识别时：右侧显示识别文字。
  - 思考时：左侧显示 "正在思考..."。

## 4. 设置页面 (Settings)
- **扁平化设计**: 单列列表菜单。
- **新增功能**:
  - **电池预览调试**: 在设置页增加 "电池水位预览" 菜单。
  - **逻辑**: 选中后，循环切换展示 0%, 20%, 50%, 80%, 100% 的电池图标效果，方便验证显示逻辑，退出后恢复真实水位。

## 5. 页面导航与防叠加 (关键 Bug 修复)
- **页面列表**:
  1. 对话 (Summary)
  2. Todo
  3. 日志 (Log)
  4. 人生进度 (LifeBar)
  5. 黄历 (Almanac)
  6. 天气 (Weather)
  7. 设置 (Settings)
- **防叠加机制**:
  - 切换到任何新页面时，**必须**先调用 `display_->DrawBlack()` (或等效清屏函数) 清空屏幕。
  - **必须**保留顶部的状态栏和标题栏。
  - 严禁残留上一页的内容 (特别是设置页的菜单项不能漏到其他页面)。

## 6. UI 视觉规范
- **空间利用**: 信息密度与可读性平衡，400px 宽度有限，注意留白。
- **反馈**: 所有操作需有明确的视觉反馈。
